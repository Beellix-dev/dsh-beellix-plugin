# Beelli X 中台插件 社区版源码

本目录维护 `@beellix-ai/dsh-beellix-plugin` 0.1.1，采用 MIT 许可。插件连接 DSH 执行底座、数据能力与场景应用，必要公共实现位于仓库内 `dev/shared`。

产品介绍与[官网入口](https://www.beellix.com)见[仓库首页](../../../README.md)。构建与验证统一从仓库根目录执行，步骤见[开发指南](../../../docs/development.md)。

## 中台入口更新

从官方 GitHub 仓库安装的中台，可在首页点击“检查更新”，发现内容变化后点击“立即更新”，校验完成后保存工作并点击“重启生效”。同为0.1.1时也能识别内容更新，无需先卸载。沿 DSH 桌面公开 CLI 和原生锁维护当前包，不改业务资料或其他插件。其他安装来源不会自动切换。此功能与业务插件的官网更新服务分别提供。
