# 常见问题

[文档中心](README.md) / 排查

| 现象 | 检查与处理 |
| --- | --- |
| 仓库地址无法安装 | 核对网络、仓库地址和 DSH 报错；包名不是当前已发布的 npm 安装源 |
| 提示版本不兼容 | 查看 DSH 原生版本及包的 `engines.dsh`，不要绕过宿主限制强装 |
| 安装后没有中台入口 | 检查入口是否启用、是否提示待重启；不要同时启用社区和企业入口 |
| 资料目录显示待接回 | 在首页选择完整旧目录，核对标记；多份目录时明确选择一份 |
| 目录已有内容但无法初始化 | 保护原件，核对是不是正确的 Beelli X 根目录；不要把已有内容当空目录覆盖 |
| 模型列表为空 | 先在主模型配置中检查 DSH 连接、模型目录及启用状态，再刷新 |
| 插件模型没有对应标签 | 检查插件是否实际安装、启用，以及是否声明模型用途；入口不能猜测每个包所需模型 |
| 余额或价格不可用 | 核对官方连接、网络及 Key 权限；自定义网关和部分提供方没有统一账单接口 |
| 场景没有右侧工作台 | 检查当前会话的场景归属、场景包启用状态及初始化；普通工作区不应展示业务场景卡 |
| 知识、数据库显示未安装 | 它们是独立能力包；安装社区入口不会同时安装所有业务插件 |
| 更新服务尚未上线 | 当前真实状态；不会把未配置或断网伪装为“无需更新” |

## 提交问题

在 [Issues](https://github.com/Beellix-dev/dsh-beellix-plugin/issues) 提供：

1. 操作系统、DSH / Next 版本和插件版本。
2. 从哪个页面执行什么操作，以及预期与实际结果。
3. 最少复现步骤；如有错误码，保留错误码。
4. 必要的脱敏日志或图片。

不要上传 API Key、账户令牌、完整 Profile、数据库、客户资料或恢复密码。涉及敏感漏洞时按[安全说明](../SECURITY.md)私下报告。

排查期间保留旧目录和备份；删除缓存、重装插件与恢复业务数据应分别确认，不使用全盘清理作为通用解决方式。
