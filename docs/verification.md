## 复现

按[开发指南](development.md)安装后执行：

```sh
corepack yarn build
corepack yarn test
corepack yarn check
corepack yarn pack --out plugin.tgz
```

`test` 执行公开仓库中的独立社区用例和官方原生接口用例；`check` 核对入口、许可、目录边界及文档链接。打包结果应只含运行文件、根清单、Bundle、说明与许可，不含测试生成的资料目录。
