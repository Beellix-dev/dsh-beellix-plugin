# 功能说明

[文档中心](README.md) / 功能

## 工作区与场景

工作区使用 DSH 原生的 `standard`、`ptc`、`minimal`、`cordis` 四类预设，对话与执行由宿主统一处理。

场景区按应用组织会话与工作台。新场景会话以 **DSH 标准预设 + 当前场景包** 执行，界面显示场景模式；场景绑定与文件执行目录分别管理。

进入场景会话后，使用该应用的工具与右侧业务工作台；已有会话保留原来的归属和配置。

## 中台页面

| 页面 | 用途 | 常用操作 |
| --- | --- | --- |
| 首页 | 资料目录与接入状态 | 初始化、选择目录、检查与重新接入 |
| 模型 | 模型连接与查询 | 主模型配置、插件模型配置、用量与余额 |
| 场景应用 | 场景状态管理 | 查看详情、启用、停用 |
| 知识与数据 | 数据能力接入 | 安装和配置相应插件，进入其功能页面 |
| 已归档对话 | 历史会话管理 | 查看、恢复、选择清理 |
| 插件管理 | 扩展安装与管理 | 本地包或 npm 安装、状态、启停与详情 |

## 自有插件的管理方式

DSH 安装社区中台入口；由中台管理的业务包保存在独立插件环境中，经原生 Loader Include 接入。它们的安装和启停由 Beelli X 管理，不重复登记到 DSH 原生插件市场的已安装列表。

插件按主要用途分类，一个包可同时提供工具、技能、页面和模型用途。安装详情集中展示依赖、启用状态和初始化要求。

## 知识与创造模式

会话知识开关用于选择当前任务可检索的知识范围。安装知识库插件后，可导入资料、整理知识并在对话中使用；开关与所选范围随当前会话保存，新会话默认关闭。

在新建的原生创造会话中，中台按启用规则提供 Beelli X 开发技能和 `beellix_develop` 工具，用于检索开发规范、检查工程描述和插件清单。具体接入规则见[开发标准](../standards/README.md)。

## 使用范围

社区版采用 DSH 本机主用户身份，面向个人电脑上的插件与场景工作。团队与企业产品的职责划分见[产品概览](product-overview.md)，服务接入进度见[验证说明](verification.md)。
