# 功能说明

[文档中心](README.md) / 功能

## 工作区与场景

工作区保留 DSH 原生的 `standard`、`ptc`、`minimal`、`cordis` 四类预设。中台不建立另一套执行引擎。

场景区用于选择已经安装并添加的场景。新场景会话以 **DSH 标准预设 + 当前场景包** 执行，界面显示场景模式；场景绑定与文件执行目录分别管理，不靠目录名推断场景归属。

场景工具和右侧工作台应仅出现在对应场景会话。旧会话不会因安装入口插件而被批量转换；空白草稿也不能被视作已完成的业务产出。

## 中台页面

| 页面 | 主要操作 | 依赖与边界 |
| --- | --- | --- |
| 首页 | 初始化、选择和检查资料目录，查看必要的连接状态 | 不是企业服务器管理台；官网账户尚未接通 |
| 模型 | 主模型配置、插件模型配置、用量与余额 | 复用 DSH 模型连接；账单能力取决于提供方 |
| 场景应用 | 查看、启用、停用已安装场景，检查详情 | 入口不附带任何业务场景 |
| 知识与数据 | 安装并打开知识库、数据中台或数据库能力 | 对应包未安装时显示未安装，不展示虚构业务功能 |
| 已归档对话 | 查看归档、恢复及按需清理 | 沿 DSH 会话服务；不把业务数据库当作聊天记录清理 |
| 插件管理 | 本地包或 npm 安装、状态、启停、详情与可用更新 | 公网发现和更新服务尚未上线 |

## 自有插件的管理方式

DSH 安装社区中台入口；由中台管理的业务包保存在独立插件环境中，经原生 Loader Include 接入。它们的安装和启停由 Beelli X 管理，不重复登记到 DSH 原生插件市场的已安装列表。

分类描述包的主要用途，不授予权限。一个包可以同时贡献工具、技能、页面和模型用途。实际可用能力仍需检查依赖、启用状态和初始化结果。

## 知识与创造模式

会话知识开关属于中台 UI；资料导入、整理、索引与检索属于知识库插件。新会话默认不自动检索全部知识；开关与所选范围跟随当前会话保存。

在符合启用时间条件的新原生创造会话中，中台注册 Beelli X 开发技能和 `beellix_develop` 工具。标准按需读取，静态检查只验证声明和工程输入，不代替构建、业务质量或实际权限验收。

## 当前不提供的能力

本包不提供企业成员、组织角色、远程多人数据库或服务器部署。官网登录、会员资格及签名更新仍是预留接入；数据中台治理业务也不包含在入口插件中。
