# 配置说明

[文档中心](README.md) / 配置

## 主模型配置

在 **模型 → 主模型配置** 中选择提供方或添加自定义连接，填写 API Key、必要的 API 地址与模型目录，保存后检查启用状态。连接保存与模型执行沿用 DSH 原生配置接口，不建立第二套主聊天模型库。

第三方或自建兼容服务应使用其实际协议、地址和模型 ID。不要把“自定义模型”理解为任意协议都能自动兼容；以宿主适配器及服务端能力为准。

已保存的密钥不在编辑界面回显；留空是否保留原值以当前表单说明为准。不要把 Key 写入 Issue、工程描述或插件安装包。

## 插件模型配置

顶部**一个标签对应一个插件**。安装并启用的插件通过包内模型用途声明，列出所需的向量、重排、文档解析或其他专用连接；中台读取声明后展示配置。

- 普通模型用途复用主模型卡片与连接编辑方式。
- 有独立配置页面的专用服务由其插件提供表单，例如文档解析服务。
- 必填用途未配置时，应阻止相关业务操作或明确显示不可用；可选用途按该插件定义回退。
- 只有声明允许复用主模型的用途才可使用主模型，不为向量或解析服务盲目套用聊天接口。

这不是“给每个场景重新选择一套主聊天模型”。DSH 主对话与图片输入仍沿原生链路，不增加通用的视觉模型转发。

## DeepSeek Search

DeepSeek 官方连接上的 Search 功能复用主连接凭据，无需在另一处重复填写同一 Key。开关可用性、API 访问资格及实际请求结果以官方服务和宿主支持为准。

自定义网关不被自动认作 DeepSeek 官方服务，也不会对未知地址猜测搜索或账单端点。

## 用量、价格与余额

| 信息 | 当前处理方式 |
| --- | --- |
| DeepSeek 官方连接 | 支持只读余额查询及官方价格页面解析；失败或结构变化时显示不可用 |
| 其他提供方 | 展示已实现的只读能力或官方价格、用量入口，不假造统一余额接口 |
| 自定义网关 | 不推测账单 API；不把未知余额显示为零 |
| DSH 本机会话计量 | 与提供方全账户账单区分，不保证涵盖账户在其他客户端的调用 |

普通推理密钥不一定有财务管理权限。币种、计量单位、缓存价格和有效时间都应按提供方返回信息核对；本页不是结算凭证。

## 官网与更新

当前发行未预置可用的官网账号和更新服务地址，不要求用户填写假地址。未配置时不伪造登录或“已经是最新版本”的结果；后续能力需由维护者发布并单独验收。
