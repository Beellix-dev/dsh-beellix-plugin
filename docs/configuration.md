# 配置说明

[文档中心](README.md) / 配置

## 主模型配置

在 **模型 → 主模型配置** 中选择提供方或添加自定义连接，填写 API Key、API 地址与模型目录，保存后检查启用状态。连接保存与模型执行沿用 DSH 原生配置接口。

连接第三方或本地服务时，选择 DSH 支持的协议，并填写服务提供的地址和模型 ID。

已保存的密钥以配置状态显示。修改连接前核对当前表单的密钥保留规则；分享配置或提交问题时移除密钥等敏感信息。

## 插件模型配置

顶部**一个标签对应一个插件**。安装并启用的插件通过包内模型用途声明，列出所需的向量、重排、文档解析或其他专用连接；中台读取声明后展示配置。

- 普通模型用途复用主模型卡片与连接编辑方式。
- 有独立配置页面的专用服务由其插件提供表单，例如文档解析服务。
- 先配置插件列出的必填用途，再启用相关业务功能；可选用途按插件定义使用。
- 声明支持复用主模型的用途，可直接选择已有主模型连接。

主模型负责 DSH 对话与原生图片输入；插件专用模型服务于向量检索、重排、文档解析等独立用途。

## DeepSeek Search

在 DeepSeek 官方连接中启用 Search，系统复用该连接的 API Key。使用前确认该连接具有相应的服务访问资格。

通过自定义网关接入时，搜索与账户查询需要对应的适配支持。

## 用量、价格与余额

| 连接或数据 | 查询方式 |
| --- | --- |
| DeepSeek 官方连接 | 只读余额查询、官方价格页面解析 |
| 其他提供方 | 已接入的只读查询，或对应的官方价格与用量页面 |
| 自定义网关 | 通过网关支持的账户接口查询；未接入时显示不可用 |
| DSH 本机会话计量 | 统计当前客户端的会话调用，与提供方全账户账单分开展示 |

账户接口可能需要独立查询权限。查询异常时可打开提供方页面，核对币种、计量单位、缓存价格和生效时间；费用结算使用提供方账单。

官网账号与更新服务的接入状态见[验证说明](verification.md)。
