# 安装与首次使用

[文档中心](README.md) / 安装

## 安装前

- 使用支持 Bundle 和客户端扩展的 DSH 客户端。已验证接口基线为 DSH `0.2.1-rc.2` / Next `2.0.19-next`；遇到版本不兼容提示时停止安装并核对版本。
- 社区版面向本机主用户，资料在本机初始化。
- 每个 DSH Profile 选择一个中台入口版本。

普通用户通过 DSH 安装即可。Node.js、Corepack 和源码构建环境仅供[开发者](development.md)使用。

## 1. 安装入口插件

打开 DSH **插件 → 添加插件**，填写：

```text
https://github.com/Beellix-dev/dsh-beellix-plugin
```

确认安装来源及包信息。宿主提示重启时，通过正常退出后重新打开生效。插件由 DSH 原生安装流程加载，仓库提供预构建运行文件。

| 渠道 | 当前状态 |
| --- | --- |
| GitHub 仓库 | 可获取社区版源码及预构建入口 |
| npm 包 | 待发布；当前请使用上方仓库地址 |

## 2. 查看资料目录

从 **更多 → Beelli X 中台** 打开首页：

1. 首次启用：安全的新资料目录会自动初始化，无需点击按钮；在首页查看实际位置。
2. 已有资料：点击 **选择已有目录**，选择完整的 Beelli X 资料根目录。
3. 等待首页显示目录已就绪；若更换目录需要重启，按页面提示操作。

默认配套目录为 DSH 安装位置下的 `Beellix`。也可选择独立磁盘位置，例如 `D:\BeelliXData`；目录必须独立于 DSH 的用户数据目录。已有内容但缺少归属标记的目录不会被当作空目录覆盖。

资料目录、目录标记与恢复边界见[数据与隐私](data-and-privacy.md)。有多份候选目录时选择其中一份，系统不会自动合并。

## 3. 配置并开始工作

进入 **模型 → 主模型配置**，配置或检查 DSH 的模型连接。然后返回工作区，使用 DSH 原生新会话开始任务。

需要业务场景时，在 **插件管理** 中安装可信的本地安装包或已发布 npm 包，再到 **场景应用** 查看状态，在左侧场景区添加已安装的场景。场景的模型和数据库等依赖由对应包声明，缺少时按页面提示补齐。

知识库、数据库和业务场景采用扩展包接入，在中台按需安装与初始化。

## 4. 检查是否生效

| 检查位置 | 应看到的结果 |
| --- | --- |
| DSH「更多」 | 存在 Beelli X 中台入口 |
| 中台首页 | 资料目录已就绪，路径符合预期 |
| 模型 | 能读取宿主模型连接，未配置的连接如实显示未配置 |
| 工作区 | 仍沿用 DSH 会话与模型执行链路 |
| 场景区 | 仅展示实际添加的已安装场景；业务工作台由对应场景包提供 |

出现异常先看[常见问题](troubleshooting.md)，不要通过删除 DSH Profile 或业务目录来试错。

插件管理中的“发现”进入官网插件市场；“可安装”和“已安装”查看本机状态。没有场景时，左侧显示安装入口，切换场景不会自动弹出选择窗口。
