# 公开仓库文件审查

[文档中心](README.md) / 公开审查

审查对象为社区版0.1.1的完整公开提交树，以及已公开历史中的高可信敏感模式。采用文件职责分类、源码依赖核对、许可检查、内容扫描与文档人工复核；不是对所有运行行为的安全担保。

## 保留的内容

| 内容 | 公开理由 |
| --- | --- |
| 社区入口源码 | 用户可查看、修改和构建实际行为 |
| 必要公共实现 | 社区版构建确实引用的组件、目录、原子写入与原生适配；不依赖未公开企业服务 |
| 根 `lib` | DSH 可直接安装 GitHub 来源，普通用户不需要先配置开发工具 |
| 锁文件和构建脚本 | 独立恢复开发环境、核对预构建来源 |
| 测试与官方 SDK 版本 | 复现社区逻辑和原生接口兼容性；测试对象为合成夹具 |
| 开发标准、Schema与示例 | 支持人工开发和创造模式按需读取；示例不冒充业务应用 |
| 许可与来源声明 | MIT 自有代码、DSH 衍生材料和第三方依赖分别署名 |

`dev/shared/console` 中的通用语言标签可以出现企业或业务名称；这些是实际构建引用的 UI 资源，不是企业服务器或对应业务应用实现。现有可读 JavaScript store 也是构建输入，保留其真实来源形态。

## 已整改

- 移除文档中的内部任务回执、旧工程路径、过期网站状态和无法查阅的历史证据指向。
- 将简短发行说明改为产品介绍和分角色文档导航，明确配置、资料、功能和交付边界。
- 补齐完整的第三方依赖许可及 DSH 衍生来源说明。
- 从公开预构建目录去除重复的 `console-client.cjs` 与 `console.css`；内容已嵌入客户端入口，构建中间文件仍由源码构建生成。
- 为发行文件使用根相对范围，避免 Yarn 收入测试目录中的同名 Bundle 文件。
- 移除编译注释中的本机构建绝对路径。
- 启用 GitHub 私密漏洞报告，统一安全问题入口。

当前检查未发现真实凭据、用户 Profile、会话、业务数据库、备份或日志。企业服务和其他业务插件源码未包含在本仓库；依赖目录和临时测试资料不提交。

## 仍需区分的边界

源码公开、MIT 许可与自动测试都不表示已完成所有安全审计、桌面版本验证或业务验收。Linux CI、真实模型任务、官网、签名更新及市场安装状态见[验证说明](verification.md)；不能把模板或规划当作上线功能。
