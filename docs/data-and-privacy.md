# 数据与隐私

[文档中心](README.md) / 数据与隐私

## 三类数据边界

| 内容 | 由谁管理 | 管理方式 |
| --- | --- | --- |
| DSH 原生对话、会话配置和执行记录 | DSH 当前 Profile | 沿用原生会话存储与配置 |
| Beelli X 目录标记、插件环境和中台配置 | 社区中台 | 在所选资料目录初始化自有结构 |
| 知识资料、场景业务库、附件和备份 | 对应业务或能力插件 | 按插件定义存储、访问与恢复 |

## 资料目录

首页显示的根目录是当前接入依据。默认位于 DSH 安装位置下的 `Beellix`，也可选择独立位置；它不能位于 DSH 用户数据目录中。

```text
Beellix/
├─ beellix-layout.json   # 目录归属和结构标记
├─ config/              # 中台配置
├─ environment/         # 自有插件环境
├─ data/                # 业务与中台运行数据
├─ knowledge/           # 知识资料
├─ files/               # 文件与附件
├─ templates/           # 模板
├─ assets/              # 应用资源
├─ cache/               # 可重建缓存
├─ logs/                # 日志
└─ backups/             # 对应插件生成的恢复备份
```

备份记录由数据库等插件生成。请在对应插件中查看最近备份时间，并按其恢复流程操作。

移动资料目录时，复制完整根目录，再通过中台首页选择并核对目录标记。遇到标记不兼容或记录损坏时，保留原件并按错误信息排查。跨系统数据库迁移使用对应插件的备份恢复流程；模型凭据与外部服务在新环境中重新核对。

## 模型、网络与凭据

- 资料默认由本机和相应插件保存；调用远程模型时，任务中发送的内容仍会交给所选提供方。
- npm 安装需要访问包源；用户打开的外部网页和第三方插件也可能联网。
- 主模型凭据沿 DSH 配置与凭据服务处理。账户、提供方和业务插件各自有边界，不将密钥返回给模型或写入公开文档。

本地插件以本机用户权限运行。会话知识开关和业务范围控制不是针对恶意本地代码的操作系统隔离；请只安装可信来源。

## 归档、卸载与恢复

归档对话仍由 DSH 保存，可在中台恢复。永久清理前核对选择对象；对话归档、附件留存和业务数据删除是不同动作。

停用或卸载社区入口默认保留资料目录。重新安装后，通过首页接回原目录，再核对业务包版本、依赖、数据库和外部服务连接。业务备份由相关插件维护，与 DSH 的客户端恢复操作分别管理。
