# 数据与隐私

[文档中心](README.md) / 数据与隐私

## 三类数据边界

| 内容 | 由谁管理 | 安装入口插件的影响 |
| --- | --- | --- |
| DSH 原生对话、会话配置和执行记录 | DSH 当前 Profile | 不另建一份聊天数据库，不批量转换旧会话 |
| Beelli X 目录标记、插件环境和中台配置 | 社区中台 | 在所选资料目录初始化自有结构 |
| 知识资料、场景业务库、附件和备份 | 对应业务或能力插件 | 本入口不附送数据，不自动合并或迁移 |

## 资料目录

首页显示的根目录是当前接入依据。默认位于 DSH 安装位置下的 `Beellix`，也可选择独立位置；它不能位于 DSH 用户数据目录中。

```text
Beellix/
├─ beellix-layout.json   # 目录归属和结构标记
├─ config/              # 中台配置
├─ environment/         # 自有插件环境
├─ data/                # 业务与中台运行数据
├─ knowledge/           # 知识资料
├─ files/               # 文件与附件
├─ templates/           # 模板
├─ assets/              # 应用资源
├─ cache/               # 可重建缓存
├─ logs/                # 日志
└─ backups/             # 对应插件生成的恢复备份
```

**出现目录不代表已经备份。** 数据库快照、持续保护、物理副本及云备份由数据库等提供方实现和验收，社区入口本身不保证这些能力。

目录复制或换位置后，通过首页选择完整根目录并核对标记；不要只复制 `data` 中某个文件。检测到不兼容标记、损坏记录或链接目录时应停止接入，不能用空状态覆盖原件。目录位置记录及其恢复还受本机环境影响，不承诺复制到任何系统后自动恢复全部凭据和外部服务。

## 模型、网络与凭据

- 资料默认由本机和相应插件保存；调用远程模型时，任务中发送的内容仍会交给所选提供方。
- npm 安装需要访问包源；用户打开的外部网页和第三方插件也可能联网。
- 主模型凭据沿 DSH 配置与凭据服务处理。账户、提供方和业务插件各自有边界，不将密钥返回给模型或写入公开文档。
- 官网与更新地址未配置时，中台不会访问占位服务。

本地插件以本机用户权限运行。会话知识开关和业务范围控制不是针对恶意本地代码的操作系统隔离；请只安装可信来源。

## 归档、卸载与恢复

归档对话仍由 DSH 保存，可在中台恢复。永久清理前核对选择对象；对话归档、附件留存和业务数据删除是不同动作。

停用或卸载社区入口默认保留资料目录。重新安装后可接回原目录，但是否能继续使用各业务包还取决于版本、依赖、数据库及外部服务状态。不要把 DSH 恢复模式当作业务备份方案，也不要通过删除 Profile 来排查连接故障。
